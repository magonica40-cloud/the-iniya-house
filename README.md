## 🌟 Overview
**The Iniya House** is a premier event management and experiential architecture company based in Bengaluru. Built on the core philosophy that *storytelling drives creativity*, Iniya House has successfully executed **100+ projects** across high-stakes corporate summits, destination offsites (MICE), brand activations, and curated executive gifting.

### Core Divisions
1. **Events**: Corporate town halls, medical conclaves (e.g., Oncology Collegium South India), product launches, sports meets, gala evenings, and private royal celebrations.
2. **Leisures (MICE)**: Turnkey corporate offsite management, venue discovery, luxury resort buyouts, heritage fort retreats, and curated day-out experiences.
3. **Branding**: Experiential activations, cinematic business explainer videos, and strategic creative campaigns.
4. **Corporate Gifting**: Bespoke employee welcome kits, client appreciation hampers, electronic gadgets, vegan leather planners, and custom crystal trophies.
5. **Standalone AV Equipment Rental**: Audio-visual inventory from single projector and PA systems to full concert line-array sound, intelligent moving heads, and 4K curved LED walls.

## 🚀 Getting Started

### Prerequisites
- Node.js (v18+)
- pnpm (recommended) or npm

### Installation
```bash
# Clone the repository
git clone https://github.com/magonica40-cloud/the-iniya-house.git

# Navigate to the project directory
cd the-iniya-house

# Install dependencies
pnpm install
```

### Development
```bash
# Start local development server with HMR
pnpm run dev
```
Open [http://localhost:5173](http://localhost:5173) in your browser.

### Production Build
```bash
# Compile and build bundle
pnpm run build

# Preview production build locally
pnpm run preview
```
